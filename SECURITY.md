# Security Policy

We take the security of Orite seriously. If you discover a security vulnerability, please report it to us so we can fix it as soon as possible.

## Reporting a Vulnerability
Please **do not** report security vulnerabilities in public Issues. Instead, report them by:

1. Opening a new private **GitHub Security Advisory** in this repository.
2. If you are unable to do that, you can contact the project manager directly through the project's issue tracker with the label "Security".

## What we will do
- We will acknowledge your report within 48 hours.
- We will work to resolve the issue and provide an update as soon as possible.
