# Contributing to Orite

Thank you for your interest in contributing to Orite! We are part of the **LuoLaf team**, and we highly value respect and quality. Please read the following guidelines before starting.

## Participation Rules
1. **Coordination:** Before starting any work or adding new features, you must coordinate with the Project Manager (President).
2. **Onboarding:** First, take time to familiarize yourself with the platform before proposing changes.
3. **Clean Code:** All code must be clean, maintainable, and consistent with the project's programming language.
4. **Documentation:** All new code must include comments in English to ensure clarity.
5. **No Compensation:** The LuoLaf team does not provide any financial compensation for contributions.
6. **Code of Conduct:** We value respect and adherence to these rules above all else. 
7. **Zero Tolerance:** Any form of disrespect towards the team will result in an immediate block.
8. **Final Approval:** Before applying any changes, you must obtain approval from the Project Manager.

## How to Contact the LuoLaf Team
To coordinate your participation, please do not send personal emails. Instead, follow these steps:
1. Open a new **Issue** in this repository.
2. Clearly describe your proposed feature or improvement.
3. Wait for the Project Manager to review and approve your request.
This ensures all project communications are tracked and organized.
