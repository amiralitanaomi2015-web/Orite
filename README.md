# Orite - Personal Planner & World Clock

Orite is a smart personal planner and world clock application designed to help you manage your time and tasks effectively.

## Features
- **Task Management:** Create, track, and manage your daily tasks.
- **World Clock:** Stay updated with time across different time zones.
- **Local Storage:** Your data is saved locally for quick access.
- **Clean UI:** A simple and intuitive interface for better productivity.

## فارسی (Persian)
پروژه **اورایت (Orite)** یک ابزار هوشمند برای مدیریت زمان و برنامه‌ریزی شخصی است. این پلتفرم به کاربران کمک می‌کند تا کارهای روزانه خود را مدیریت کنند و در کنار آن، زمان دقیق در نقاط مختلف جهان را مشاهده نمایند.

### ویژگی‌های اصلی:
- مدیریت وظایف روزانه (To-Do List).
- نمایش ساعت جهانی (World Clock).
- ذخیره‌سازی محلی برای دسترسی سریع.
- رابط کاربری ساده و کاربرپسند.
